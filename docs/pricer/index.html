HOW IT WORKS

This model computes the intrinsic value of a gas storage asset by solving a linear program over the forward curve.

Objective — Maximize: withdrawal revenue − injection cost − operational costs.

Constraints

  • Inventory ≤ maximum capacity
  • Storage level ≥ 0 at all times
  • Injection and withdrawal volumes capped per month
  • Final inventory = initial inventory
